# 安全说明

## 报告问题

**不要在公开 issue 里贴任何凭据。** 这一条比下面的流程都重要 ——
本项目的 issue 里一旦出现订阅链接，等于把节点直接交出去。

- 一般问题：开 issue，但**只描述现象**（哪一步失败、报什么错），把订阅链接、uuid、
  公钥、密码全部打码。
- 涉及凭据泄漏、权限提升、命令注入等敏感问题：请**私密报告**（仓库 Security 页面 →
  Report a vulnerability），不要开公开 issue。

## 这个项目里什么算凭据

不只是密码。以下**全部**属于凭据，任何一条泄漏都等于节点被白用：

| 项目 | 说明 |
|---|---|
| 订阅链接 | 机场把它当身份标识，谁拿到谁能拉全部节点 |
| 节点 `uuid` / `password` | 直接可以连 |
| Reality `public_key` / `short_id` | 配合地址即可连 |
| 生成的 sing-box 配置 | 里面包含上面全部字段 |

**因此**：

- 状态目录 `0700`，状态文件与生成的配置 `0600`。
- `store.redacted()` 是唯一的对外视图；接口和界面都拿不到上述字段。
- 日志不打印 uuid / 公钥 / 密码。
- `var/`、`cache.db`、`app.lock` 在 `.gitignore` 里。
- 测试里的样本（`test/sample.mjs`）只用 RFC 5737 测试网段 `192.0.2.0/24` 和
  `sing-box generate reality-keypair` 生成的结构合法假密钥 —— **随手写的假公钥会让
  内核报 `invalid public_key`**，所以连测试数据都必须是真格式。

## 设计上的安全约束

**控制 API 只监听回环地址。** `/api/connect`、`/api/settings` 这类接口能启停代理、
改系统设置。`server.mjs` 默认绑 `127.0.0.1`；`--host 0.0.0.0` 是给远程调试用的，
用了等于把这个能力开放给局域网。

**跨源只放行桌面壳。** 打包后前端在 `tauri://localhost` 或 `http://tauri.localhost`，
`server.mjs` 的来源白名单**只有这两个**。

**退出顺序是安全约束，不是风格问题。** 必须先让引擎断连（还原系统代理），再收进程。
直接 `kill -9` 会把用户的系统代理永久留在我们改过的状态上 —— 表现是"突然上不了网"，
而用户根本想不到是代理客户端干的。引擎自身处理 `SIGTERM`，外壳侧也有两道保险。

**提权不做静默尝试。** 需要权限时明确报 `NEED_ELEVATION` 并给出可复制的提权命令，
由用户确认。不后台偷提权、不写 setuid 助手。

## 已知边界

- 系统代理适配器会改注册表 / 网络设置。还原逻辑有单测，但**真机往返验证**需要用户执行
  `tools/macos-sysproxy-roundtrip.mjs`（macOS）或对照 `tools/macos-preflight.sh` 的思路自行确认。
- TUN 模式需要管理员 / root。`auto_route` 会改写默认路由；内核被 `kill -9` 时可能残留，
  表现为突然断网。排查：看默认路由是否指向 utun / wintun 适配器。
- 本应用不带代码签名与公证。首次打开需要 `xattr -cr` 或右键打开。**不要**为此关闭
  Gatekeeper 全局保护。
- 依赖面很小：运行时零第三方依赖（只用 Node 内置模块），开发依赖只有 `esbuild` 与
  `postject`（仅打包 sidecar 时用）。
